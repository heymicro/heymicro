Install Micro.

For Linux or macOS. On Windows, use WSL2. Prefer no setup? Use Micro online.

1. Install

Open a terminal and run:

curl -fsSL https://raw.githubusercontent.com/micro/mu/main/install.sh | sh

2. Start

~/.local/bin/mu --serve --address 127.0.0.1:8080

3. Open Micro

Go to localhost:8080. Create your account and choose an AI provider. You can skip the provider for now; the assistant needs one to answer questions. A hosted provider needs an API key; a local provider needs a running model.

Keep the terminal open while using Micro. Press Ctrl+C to stop; use the same start command next time. Your data stays in ~/.mu.

For hosting, model configuration and other options, see the documentation.
