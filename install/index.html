Hey Micro 👋

Self-host Micro.

To add Micro to your phone or computer without running a server, install the app.

For Linux or macOS. On Windows, use WSL2. Prefer no setup? Use Micro online.

1. Install

Open a terminal and run:

curl -fsSL https://micro.mu/install.sh | sh

2. Start

mu --serve

If your terminal does not recognise mu, close and reopen it after installation.

3. Open Micro

Open localhost:8080 in your browser. Create your account and choose an AI provider. You can skip the provider for now; the assistant needs one to answer questions. A hosted provider needs an API key; a local provider needs a running model.

Keep the terminal open while using Micro. Press Ctrl+C to stop; use the same start command next time. Your data stays in ~/.mu.

For hosting, model configuration and other options, see the documentation.
